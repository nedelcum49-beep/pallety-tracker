
# Trailer Pallet Tracker (Production)

## Features
- JWT Authentication
- Operator tracking
- Immutable audit log
- Auto-close trailer at 26 pallets
- Hard pallet duplication lock
- PDF label endpoint
- Zebra ZPL export
- Mobile-first scan UI

## Run

docker compose up --build

API: http://localhost:8000/docs
Web: http://localhost:5173
